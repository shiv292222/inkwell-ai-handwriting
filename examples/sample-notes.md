# How memory works

Memory is not a single box in the brain. It is a set of processes that encode, store, and retrieve information.

## Three useful stages

- Encoding changes an experience into a form the nervous system can store.
- Consolidation stabilizes a memory over time, especially during sleep.
- Retrieval reconstructs stored information when it is needed.

## Better study habits

- Use active recall instead of only rereading.
- Space reviews across several days.
- Mix related problem types instead of repeating one pattern.
- Explain the idea in your own words.

The goal is not perfect repetition. The goal is being able to retrieve and apply the idea in a new situation.
