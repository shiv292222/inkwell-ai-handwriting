# Contributing

Thanks for helping improve Inkwell.

1. Open an issue describing the user problem before a large change.
2. Keep the Python production renderer deterministic, measured, collision-safe, and shared by CLI and MCP.
3. Do not commit note samples containing personal data, proprietary fonts, external model weights, or secrets.
4. Add behavior-focused tests, render PDF/DOCX changes for visual review, and run `npm run check`.
5. Submit a focused pull request explaining security and privacy implications.

By contributing, you agree that your work is licensed under the MIT License.
